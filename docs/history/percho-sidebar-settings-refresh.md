# 左侧栏、文件面板与设置界面收拢

本轮按使用反馈收拢导航与管理入口：左侧栏不再承载第二套「会话进程／归档」页面，设置页去掉按会话配置，文件面板改为左右分栏。视觉上只做结构性调整，沿用 Percho 的语义 token、`Button`、`Switch`、`ConfirmDialog` 与既有排版，不新增装饰性外壳。

## 交互变化

| 原位置 | 现行为 |
| --- | --- |
| 左栏底部「会话进程」「归档会话」两个按钮 | 移除；进程启停／重启、归档、恢复、项目信任全部在会话行右键菜单 |
| 归档需要切换到独立列表 | 左栏搜索框旁新增「视图选项」：分组方式（按工作区／单列表）、排序（最近更新／按名称）、筛选（隐藏已归档／全部对话／仅显示已归档），持久化在 `ui-state.json` |
| 归档会话只能从归档列表恢复 | 在「仅显示已归档」中右键恢复；直接点击归档会话会先恢复原生历史再打开 |
| 设置 → 会话配置 | 移除；所有会话继承 Pi 全局设置。审批仍在输入区的权限选择器，模型仍可在输入区切换 |
| 设置导航平铺 12 个分类 | 分为「应用／模型与资源／人格与提示／系统」四组；标题与一句话说明在内容区顶部，面板内不再重复分类名 |
| 设置里的原生 `<select>` | 小集合改用 `settings/Segmented` 单选（配置范围、语言、上下文管理），大集合仍用下拉 |
| 右侧文件面板上下堆叠 | 文件树固定在右栏左侧，预览在右侧；空预览给出选择提示，预览关闭不清空树 |

## 实现边界

- `SessionMeta.archived` 是目录投影字段；`session-transport` 不再丢弃归档 Agent，`openSession` 在打开前调用原生 `agent.restore`，不复制或改写归档库。
- 删除／归档后重新读取目录，避免本地列表与真实 Agent 成员漂移；`useWorkspaceObservation` 在成员或归档状态变化时重拉会话目录。
- 「视图选项」是瞬时弹层（Esc、外点、滚动关闭）；选择本身是持久化偏好，不新增执行入口。
- 会话右键菜单的原生动作仍走 workspace 命令与 revision；只读子会话与 Pi 历史行的既有约束不变。
- 按会话配置的 UI 已删除，但原生 `agent.prompt`／`configure` API 与数据保留；本轮不迁移或删除已有原生配置。
- 文件分栏复用原有 `/api/files` 与边界校验；只改布局。
