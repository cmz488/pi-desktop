## 边界审查

固定 origin／包名／过滤器；12 秒、4 MiB 响应、4 并发、32 项／8 MiB／60 秒缓存，transport 关闭清理自有请求。第三方文字不获得本地控制属性或自动加载媒体的能力。

原生检查／包写互斥，操作校验共享空闲、原 session/cwd、project trust、配置 revision 与磁盘版本清单指纹；配置／版本变化会使提示失效，迟到结果不改派。原生 update(source) 按来源 identity 匹配范围，确认不假装任意 scope 更新；持久化失败明确提醒磁盘可能已有副作用，不自动回滚。

包管理器和作者代码不是 OS 沙箱；不使用私有运行时字段、不修改 Pi 核心／第三方安装、不建立第二套包数据库或安装器。老宿主没有能力则说明并禁用，不调用不存在的接口。

## 剩余限制

官方 HTML 不是版本化 JSON API，未来结构变化会明确失败并指向原页面。原生 checker 不返回远端版本号，部分来源／网络／离线情况无法判断最新；更新提示保留检查时间，不保证持续实时。原生安装可能运行第三方代码、脚本与网络请求，需自行审核。

手机仍为浏览器宽度模拟，不等于真实 OS／文件管理器验收。真实旧宿主需所有任务结束、草稿和附件保存后授权加载新后端；只刷新页面不能更新后端能力。
