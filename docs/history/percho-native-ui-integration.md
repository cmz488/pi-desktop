# Percho 原生能力整合

本轮把已接通的 pi-desktop 后端能力归入 Percho 的现有界面，移除聊天页顶部「Pi 工作台」、工作台弹窗、旧页面 HTML 模板与整套工作台样式。

## 功能位置

| 位置                                  | 能力                                                                                                               |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 左侧项目与会话                        | 项目目录添加与校验、项目重命名、会话创建、重命名、置顶、项目信任、进程启动／停止／重启、Pi 历史接管                |
| 左侧底部                              | 会话进程列表、归档列表与恢复、Percho 设置入口                                                                      |
| 设置 → 通用                           | Pi 原生模型默认值、工具和上下文配置，按内容 revision 保存 patch、继承值、重载并应用                                |
| 设置 → 人格与提示词                   | 全局 AGENTS.md、可选人格编辑                                                                                       |
| 设置 → 会话配置                       | 指定会话的人格、三档审批、模型、cwd、工具、Durable 扩展、额外指令、Shell 与环境变量                                |
| 设置 → 网络与重试／资源与 Shell／外观 | Pi schema 对应分类；Percho 界面外观与 Pi 终端显示分别配置                                                          |
| 设置 → 模型／Skills／MCP／扩展        | 沿用 Percho 的提供商、认证、MCP 与目录组件；补入技能启停、模板与扩展命令、已安装包、原生更新、启停、资源过滤及重载 |
| 右侧 → 文件                           | 项目目录树、文本／图片预览、工作区边界校验                                                                         |
| 右侧 → 网页                           | 选定 worker 的共享 Chromium、标签页、地址与导航、画面和输入；兼容 Electron 原生浏览器                              |
| 右侧 → 会话改动／Git                  | 原有按轮次 diff，完整仓库暂存、提交、历史图、分支／标签与远端操作                                                  |
| 右侧 → 任务                           | 委托草稿与幂等提交、原生任务与详情、等待／中止、终态历史、对话分支与扩展面板                                       |
| 右侧 → 侧聊                           | pi-btw 独立讨论、取消及带回主输入框                                                                                |

Slash 命令也导航到这些真实位置。侧栏会话选择只改变观察对象；不切换主聊天、不改变执行所有权。关闭任务或浏览器面板只清理观察，任务与 Chromium 的执行生命周期仍归所属 worker。

## 接线与样式

`components/native/` 现在是 React 功能组件，使用 Percho 的 `Button`、`Switch`、`ConfirmDialog`、菜单、设置分类、侧栏状态和语义颜色 token。原生 API、配置 revision／原子写入、共享空闲门禁、Git 预览 token、显式信任与原生 JSONL 均保持既有边界。

浏览器画面适配器增加可选 `framePath`，由选定会话生成 worker 地址，修复根 Host 页面错误读取默认画面路径的问题。默认地址仍兼容原有直接宿主 URL。

## 异步操作回归修复

后续审查的五项问题已沿现有界面和协议修复：侧聊取消独立于提问的等待状态；委托提交期间锁定原表单；人格与运行时设置共用加载状态，刷新原生 revision 时保留未保存字段；文件预览只接受最后一次文件选择的回复；Electron 回退按主进程的 owner／标签 UUID、动作和单标签回执适配，隐藏面板保留原生网页。

`test/ui-parity-browser-check.mjs` 追加延迟委托回执、乱序文件回复、人格变更后保留草稿并保存，以及真实侧聊模型请求挂起时取消。`test/ui-next-native-browser.test.mjs` 复用实际 `createBrowserPanels` 处理函数，用模拟 WebContentsView 验证协议、标签选择／关闭、观察隐藏与 owner 隔离；这项测试不替代 Electron 窗口的平台验收。

## 验证

`npm run test:ui-next:browser` 从实际左右侧栏和设置操作，验证原生聊天与状态、保留的委托草稿、真实子代理与关闭观察、文件预览、真实 Chromium 画面及 worker 绑定、Git 暂存与确认提交、原生设置保存、人格、提供商与包管理入口、侧聊隔离，以及窄屏和主题。脚本同时捕获 HTTP 失败、页面异常与未处理 Promise。

Node 契约与后端测试继续验证原生存储／进程／配置等语义；发布检查使用重新构建并实际解包的 npm 产物验证所有模块与浏览器引用。
