发现并修复的行为问题：`AsyncLocalStorage` 的后代回调可以比目录枚举长寿，枚举结束后的实际认证曾读取旧视图。真实 SDK resolver 的延迟回调红测得到 `fixture-old` 而非 `fixture-new`；修复在操作完成／失败时释放视图，后代回调重新读取文件。原来的并发认证、注销、回调内修改与每操作两次读取仍通过。

未将无可靠来源的旧内容当作自动注入：完整回退并标明来源未记录。纯界面控制命令维持控件动作；自行处理的扩展命令只增加 `model: []` 展示记录，不伪造模型回合。来源关系不授予任务、子代理或旧 worker 权限。

## 性能证据与限制

完整定义、前后各六轮、分配诊断、原文标注成本及最终三轮全指标见[性能记录](../references/session-redesign-performance.md)。固定两 worker、60 轮 512 字符历史、12 次切换与面板操作、40×20ms 流式，每轮 **87** 次 provider 请求；主线程长任务均为 0。

最终三轮切换 median 为 5.8／6.2／4.9ms，p95 为 12.1／13.4／25.5ms；自然 RSS 历史 worker 中位数 **229.54 MiB**，优化前六轮为 **240.97 MiB**。确定性改善是重复请求与文件读取，不能宣称全部延迟、事件流连接、GC 后保留内存或峰值都下降。mutation／layout／Task 指标不是硬件绘制时间，有限重复不能证明长期无泄漏。

独立 worker 架构成本另列：三轮额外进程自然 RSS 186.40／194.22／194.95 MiB，工具边界 GC 后约 130 MiB；不计为优化收益，不引入新的回收策略。
