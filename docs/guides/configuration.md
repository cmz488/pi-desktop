# 配置与原生资源

设置面板管理 Pi 全局配置、模型提供商、人格、扩展／Skills／模板、MCP 与外观。原生资源继续使用 Pi 的配置与发现规则，不提供 Desktop 项目／会话注入配置。

## 网络代理与外观

“Pi 配置 → 网络 → HTTP 代理”使用全局 `SettingsManager.httpProxy`，填写完整 URL，例如 `http://127.0.0.1:7897`。已有 HTTP_PROXY／HTTPS_PROXY 环境变量优先；Agent 下次启动读取新值。TLS 证书校验保持开启。Tailscale 连接独立遵循当前直连策略，见 [远程指南](remote-access.md)。

字号覆盖聊天、设置与外层项目栏；Ctrl/⌘+=、Ctrl/⌘+- 调整，Ctrl/⌘+0 复位，范围为 12–24px。

## 人格与模型

全局提示词编辑对应 agent-dir 下的 AGENTS.md；可选人格使用各自的 AGENTS.md。输入框上方选择人格。Pi 原生项目提示词发现和 AGENTS.override.md 优先级继续生效。

模型按钮显示当前模型与思考强度，使用上拉菜单。Agent 执行期间允许提交模型／思考／设置修改，影响当前执行的变更按现有延迟配置逻辑在安全时机生效。

## 文件上下文

本机 Desktop 和本机浏览器默认发送文件索引：名称和绝对路径进入消息，文件正文及图片数据不自动注入。点击加号使用主机文件选择器；文件卡片标记“本地引用”，Agent 根据任务通过已有工具按需读取。大文件、PDF 等也可引用，实际读取能力和权限仍由 Agent 的工具决定。

Desktop 粘贴的图片或文件若没有原始路径，会通过本地 IPC 保存在 Desktop 的 `context-files/` 附件缓存中，再引用该路径；缓存保留以供历史会话继续读取，单个剪贴板文件上限 4 MiB。本机普通浏览器无法从粘贴对象取得完整主机路径时，请先保存，再使用加号选择文件。

截图直接粘贴时没有原文件目录，消息中的绝对路径指向实际保存的截图缓存。Agent 按需调用 Pi 原生 `read` 读取图片，由 Pi 完成解码、缩放并将图片结果送入后续模型请求；项目会话和无项目只读会话使用同一读取逻辑。

手机等远程连接默认上传附件内容；沿用原文本／图片解析及大小限制。连接模式由 Host 确认，远程客户端不能提交主机文件引用，也不能打开主机文件选择器。切换会话会保留各自的文件索引或上传草稿；本地索引不计入上传内存限额。

## 插件与 MCP

插件可安装、卸载、启停，并支持单个更新及全量更新；由 Pi 原生包管理执行。原生资源写入沿用信任、作用域、清单指纹和共享空闲检查，更新后按提示重载。

MCP 仍使用 Pi 原生客户端、认证与 Codemode 调用链。第三方扩展的私有设置仅在有明确声明的表单或专用适配时编辑；未知配置不推断。插件会话展示见 [扩展卡片](extensions.md)。
