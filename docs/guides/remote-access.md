# 手机连接

设置中的「跨设备互联」页面管理手机端：开启后生成局域网二维码，手机浏览器扫码即用，可「添加到主屏」。

## 传输与信任

手机端在**独立端口**提供 HTTPS，证书是启动时生成的自签证书（P-256，SAN 覆盖本机局域网地址，1 年有效，剩余不足 30 天或网段变化时自动重新生成）。私钥仅本机可读，不会进入日志或发布包。

自签意味着首次访问会出现「证书不受信任」提示：这是预期行为，不是配置错误。浏览器不能靠关闭校验绕过，需要手动接受一次（或把证书安装到设备信任库）。隧道（Tailscale）已移除，手机端不经过任何第三方中继。

## 鉴权与能力

- 读端点用 `?t=<token>`，写端点用 `Authorization: Bearer`（令牌不进 URL 日志）。
- 令牌每次启动与每次重新开启都重新生成；关闭开关即撤销，旧令牌立刻失效。
- 二级开关「远程控制」默认只读；关闭时写端点返回 403，不静默丢弃输入。

手机端只能看到：会话列表、当前会话的消息历史（**最近 100 条**，超出标记截断）、发消息、停止生成。设置、插件市场、包管理、扩展工作台、浏览器自动化、目录选择与文件浏览只在电脑提供。

## 数据面

出网内容统一在 `src/server/mobile-data.mjs` 裁剪：图片只保留数量占位、本地路径与会话文件名清空、工具 details 递归处理。写操作记入工作空间数据目录下的 `mobile-audit.jsonl`（时间／来源 IP／动作／目标／结果），**不记令牌、不记正文**。连接数上限 5、单会话待发帧上限 64，超出明确拒绝而不是让慢客户端拖住 Host。

## 常见问题

- **手机打不开**：确认在同一局域网、端口未被防火墙拦截；二维码里是局域网 IP，不是公网地址。
- **提示证书错误**：自签证书的正常表现，接受一次即可；换了网络导致 IP 变化时会重新生成证书，需要重新接受。
- **看不到远端项目**：手机端只显示本机内容。
- **消息发不出去**：检查「远程控制」是否开启（默认关闭只读）。
- **想要公网访问**：当前不支持。手机端只做局域网；自建隧道属于另一次架构决策，不在现有能力范围内。
