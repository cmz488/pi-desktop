# 手机远程连接

设置中的“远程连接”管理现有 Tailscale 入口；完成电脑登录、HTTPS／Funnel 授权后生成二维码，手机浏览器扫码访问同一工作空间。二维码发布前进行严格公网 HTTPS 校验，不关闭证书校验。

Tailscale CLI、用户态守护进程与 Funnel 子进程使用独立的无代理环境；系统代理变量不会进入这些子进程。系统 tailscaled 若仍受代理影响，可在本机运行 `scripts/configure-tailscale-proxy.sh --check` 诊断，授权后运行 `scripts/configure-tailscale-proxy.sh` 清除其代理环境。应用不自动执行 sudo、不改 DERP 区域、不关闭 TLS；守护进程异常退出时有有界重启，隧道恢复后重新建立扫码入口。普通 Pi 模型代理设置独立生效。

远程连接保留会话、新建会话、会话管理、附件、文件预览与 Git。设置、插件市场／包管理、扩展工作台、浏览器自动化页面、本机目录选择、添加项目和 Agent 主机配置（cwd、Shell、环境、工具、扩展）只在电脑提供；远程请求会被拒绝，外层工作区与聊天入口也会隐藏。手机嵌入聊天仍可通过侧栏按钮打开会话列表。聊天内的只读扩展卡片随会话显示。

手机端优先优化会话页、会话列表与输入区，覆盖 320／360／390／430px、安全区、触控尺寸和浅色／深色／减少动态效果。导航只传项目／会话索引；聊天默认读取近期消息，思考与工具正文按展开加载。文件面板的目录索引会被文档树复用，打开文本、图片、二进制和大文件时按既有预览上限返回内容或明确错误，不把主机路径暴露给远程。

右侧文件栏只列当前目录，点开文件才由 Host 返回预览。JSON 和静态资源协商 Brotli／gzip，未变 GET 使用 ETag，私有响应仅暂存于页面有界内存。断线按事件游标重连；授权失效提示重新扫码，不无限重试。

远程添加上下文文件时上传手机上的文件，Host 缓存后只把缓存路径交给 Agent；本地连接只发送主机文件索引。两者由后端区分，远程不能通过伪造文件索引读取主机路径或触发主机选择器。详见 [文件上下文](configuration.md#文件上下文)。

实网检查、先前证书与代理排查保存在 [历史连接验收](../history/remote-access-review.md)和[传输测量](../history/performance-check.md)，其中环境与日期不可泛化为当前连接保证。
